# Quem é quem no MelipoNet

Esta tabela existe por dois motivos. O primeiro é prático: quando um pull request precisa
de revisão, ou quando alguém acha um defeito no firmware, dá para saber a quem chamar. O
segundo é pedagógico — acrescentar a própria linha aqui é o **pull request de treino**, o
primeiro de cada pessoa no projeto, feito num arquivo onde nada pode quebrar.

Como fazer o seu:

    git switch -c docs/meu-nome-na-equipe
    # acrescente a sua linha na tabela abaixo
    ./verificar
    git commit -am "docs: <seu nome> entra na equipe"

Depois abra o pull request com os três blocos de sempre — o que muda, por quê, como
verifiquei — e peça a revisão do orientador. O ciclo inteiro está em
[Como trabalhamos](guia/05-como-trabalhamos.md).
